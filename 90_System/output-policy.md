# 出力ポリシー — 生成マーカー（すかし）禁止

## 方針

brain内のノート本文には、生成元・実行者・AIモデル名を示すマーカーを**一切入れない**。

## 背景

`/orchestrate` `/weekly-review` `/deep-research` 等の出力に、その場の即興でフッターが付いていた。
書式は不統一（大文字小文字・記号・位置・モデル名の有無がバラバラ）で、
判別にも使えず、ノートの再利用時にノイズになるだけだった。

## 禁止する表記

| 種別 | 例 |
|---|---|
| 末尾フッター | `*Generated by /orchestrate — 2026-03-27*` |
| モデル名入り | `_生成: Claude Code (claude-sonnet-4-6) / orchestrate_` |
| 冒頭メタ行 | `実行者: Claude Sonnet 4.6` / `- **実行者**: Claude Code（Thinking Partner）` |
| 自動生成表記 | `作成: orchestrate 自動生成` / `*自動生成: weekly-review 2026-03-20*` |
| 絵文字マーカー | `🤖` |

## 許可する表記

コマンドの記録が必要な場合のみ、以下の形式を使う（AI名・モデル名は書かない）。

```markdown
実行コマンド: `/orchestrate`
作成: 2026-05-08（/weekly-review）
```

## 適用範囲

**出力先を問わず適用する。**

| 対象 | 状態 |
|---|---|
| brain内ノート本文（全フォルダ） | 適用済み |
| brain外の作業フォルダ（論文プロジェクト等） | 適用（`90_System/no-watermark-global-rule.md` の手順でPC側に設定） |
| 本文以外（frontmatter・HTML/LaTeXコメント・ファイルのメタデータ） | 適用 |
| gitコミットメッセージ（`🤖 自動: ...`） | 適用外（brainの自動実行コミット識別子として維持） |
| GitHub上のIssue/PRコメント | 適用外（Claude Code側の仕様でフッターが自動付与され抑制不可） |
