# 生成マーカー禁止ルール — brain外プロジェクトへの適用手順

brain（このリポジトリ）のルールは `.claude/CLAUDE.md` に書いてあるため、**brainフォルダ内で作業しているときにしか効かない**。
`C:\Users\hnak\Dropbox\MyPaperProject\MyPaperProject20260627` など別フォルダにも効かせるには、下記のどちらかを実施する。

## 方法A: ユーザー全体に適用（推奨）

`C:\Users\hnak\.claude\CLAUDE.md` に追記する。このファイルはPC上のすべてのフォルダで読み込まれるため、
MyPaperProject を含む今後のあらゆるプロジェクトに一度で効く。

PowerShell（コピーして実行）:

```powershell
New-Item -ItemType Directory -Force -Path "$env:USERPROFILE\.claude" | Out-Null
Add-Content -Path "$env:USERPROFILE\.claude\CLAUDE.md" -Encoding UTF8 -Value @'

## 生成マーカー（すかし）禁止

出力先・ファイル形式を問わず適用する。

- 生成した文章に、生成元・実行者・AIモデル名を示すマーカーを一切書かない
- 禁止する場所: 本文 / 末尾フッター / 冒頭メタ行 / YAML frontmatter / HTML・LaTeXコメント / ファイルのメタデータ（作成者プロパティ等）
- 禁止する表記例:
  - Generated by ... / Generated with Claude Code
  - 生成: Claude ... / 自動生成: ... / 実行者: Claude ...
  - Co-Authored-By: Claude
  - % Written by AI / <!-- generated by ... -->
  - 🤖 などの生成物を示す絵文字マーカー
- 「この文章はAIが生成した」と読み取れる痕跡を、本文にもメタデータにも残さない
- コマンド名の記録が必要な場合のみ「実行コマンド: /xxx」の形式で書く（AI名・モデル名は書かない）
- 例外: GitHubのIssue/PRコメントに自動付与されるフッター（ツール仕様で抑制不可）
'@
```

## 方法B: そのプロジェクトだけに適用

`C:\Users\hnak\Dropbox\MyPaperProject\MyPaperProject20260627\CLAUDE.md` を作成し、
方法Aの `## 生成マーカー（すかし）禁止` 以下と同じ内容を書く。
論文プロジェクトなど、そのフォルダ限定でルールを完結させたい場合に使う。

## 論文プロジェクトでの追加注意

| 形式 | 混入しやすい箇所 | 対処 |
|---|---|---|
| LaTeX | `% Generated by ...` のコメント行 | コメントにも書かない |
| Word (.docx) | 作成者・会社・最終更新者プロパティ | ファイル > 情報 > ドキュメント検査で削除 |
| PDF | Producer / Creator メタデータ | 書き出し後にメタデータを確認 |
| Markdown | frontmatter の `generated_by` 等 | フィールド自体を作らない |
| git | コミットメッセージの `🤖` / `Co-Authored-By: Claude` | 通常のメッセージのみにする |

## 確認コマンド

適用後、対象フォルダで混入を検査する（PowerShell）:

```powershell
Select-String -Path "C:\Users\hnak\Dropbox\MyPaperProject\MyPaperProject20260627\*" -Recurse `
  -Pattern "Generated by|Generated with|Co-Authored-By: Claude|自動生成|実行者: Claude|🤖"
```
